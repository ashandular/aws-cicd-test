Work

This portfolio, self-hosted on AWS

A static site served from my own EC2 server instead of a hosting platform, with HTTPS and automatic deploys on every push.

Domain from Namecheap, Elastic IP so the address never changes, and a free certificate that renews itself.

  1. Push to GitHub triggers a GitHub Actions workflow
  2. Deploy copies the files to the server’s web folder
  3. Nginx on Ubuntu serves the site on ports 80 and 443
  4. Let’s Encrypt issues and renews the HTTPS certificate
  5. Namecheap DNS points ashandulara.me at an Elastic IP
